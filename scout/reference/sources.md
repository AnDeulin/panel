## Лучшие практики: 7 типов источников

| Тип | Что ищем | Чем |
|---|---|---|
| Документация и стандарты | официальные правила, гайды, спецификации | WebSearch → WebFetch первоисточника; цифры и цитаты — из сохранённого текста, не из пересказа |
| Лучшие реализации в мире | как сделали лидеры | WebSearch «best X», «top X examples»; для интерфейсов — снимки эталонов |
| Лучшие в России | местная практика, язык клиента, право | WebSearch по-русски; VC, Хабр |
| Проекты на GitHub | готовые решения и методы | `gh search repos "тема" --sort stars --limit 20`, читать README |
| Разборы экспертов | почему так, а не иначе | статьи, YouTube |
| Грабли | что не сработало у людей | Reddit, форумы, Хабр, VC, комментарии YouTube |
| Данные и исследования | цифры, эксперименты | arXiv, отраслевые отчёты — через WebSearch |

Минимум 5 типов из 7. Тип не дал ничего — записать «искал, не нашёл», а не пропустить молча.

## Формулировки

3–5 на тему, обязательно по-русски и по-английски:
- «как делают X» / «how to X»
- «X лучшие практики» / «X best practices»
- «X github» / «awesome X»
- «X ошибки» / «X pitfalls», «X mistakes»
- «X против Y» / «X vs Y»
- для навыков: «X skill», «X agent skill», «X SKILL.md»

1. **Каталог Anthropic внутри Claude** — встроенный поиск плагинов (инструмент SearchPlugins). Плагины помечены как прошедшие проверку каталога, есть уровень «anthropic». Установка — карточкой (SuggestPluginInstall), пользователь подтверждает сам. 27.10.2026 по «research, marketing, design» — 10 сборников: Design от Anthropic, маркетинг, UX, продукт. Свои навыки на claude.ai — инструмент SearchSkills.
2. **anthropics/skills** (GitHub, 184 тыс. звёзд) — официальные навыки. Список: `gh api repos/anthropics/skills/contents/skills --jq ".[].name"`.
3. **Сильные библиотеки GitHub** (звёзды на 27.10.2026): obra/superpowers 306 тыс. (поэтапная работа, отладка, проверка), addyosmani/agent-skills 111 тыс. (инженерия), Leonxlnx/taste-skill 103 тыс. (арт-дирекшн), mvanhorn/last30days-skill 66 тыс. (поиск по Reddit, HN, YouTube — со скриптами, уровень 2), K-Dense-AI/scientific-agent-skills 55 тыс., cloudflare/security-audit-skill 49 тыс. Обновить список: `gh search repos "agent skills" --sort stars --limit 20`.
4. **skills.sh** — `npx --yes skills find "запрос"`. Бесплатно, без входа; это запуск программы — один раз спросить разрешение. Выдаёт навыки с числом установок и ссылкой. Только поиск; ставить — по уровням из `vetting.md`.
5. **Поиск файлов навыков на GitHub** — `gh search code "тема" --filename SKILL.md --limit 20`. Много случайного — только с проверкой.
6. **SkillsMP** (skillsmp.com) — индекс миллионов файлов SKILL.md без отбора. Как поисковик; качество проверять у первоисточника.

## Что обходить

- **ClawHub (OpenClaw)** — массово заражён в 2026 (Snyk ToxicSkills). Не брать.
- **Зеркала** (LobeHub, claudemarketplaces, aiskill.market, agenticskills и др.) — копии; идти к первоисточнику на GitHub и проверять там.
- **Каталоги MCP-серверов** — это программы: всегда уровень 2.
- **Похожее название — не оригинал.** Пример 27.10.2026: «superpowers» с навыком landing-page-design у 101-skills, magentosh, qu-skills — это не obra/superpowers (в оригинале такого навыка нет).

## Команды и грабли Windows

- Вывод `gh` через python в консоль — перед этим `export PYTHONIOENCODING=utf-8`, иначе падает на кириллице и символах вроде ★.
- `npx` — с `NO_COLOR=1` и флагом `--yes`, иначе спросит подтверждение и повиснет.
- `gh` иногда рвёт TLS-соединение — повторить запрос.
- Пересказ WebFetch может пропустить факт — цифры и цитаты брать из сохранённого текста страницы.
