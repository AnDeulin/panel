# Реестр разведки

Что уже нашли — чтобы в других диалогах не искать заново. Перед разведкой заглянуть сюда. При явной просьбе пользователя «перепроверь» — искать заново и дописать разницу с новой датой.

- `skills.md` — навыки ИИ: найденные, проверенные, подключённые или отклонённые.
- `topics/<тема>.md` — разведка по теме: таблица приёмов, источники, дата, что взяли.

Правила записи: дата в каждой строке; источник — ссылкой; старое не стирать, а помечать «устарело (дата)». Заполненный реестр — личный: в публичные репозитории не отправлять.
