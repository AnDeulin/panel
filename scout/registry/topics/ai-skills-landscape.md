## Безопасность

- Snyk ToxicSkills, февраль 2026: 3 984 навыка из ClawHub и skills.sh; 36,82% с уязвимостью, 13,4% с критической, 76 вредоносных; 91% вредоносных используют внедрение команд в текст. https://snyk.io/blog/toxicskills-malicious-ai-agent-skills-clawhub/
- В 2026 вышли исследования методов поиска вредоносных навыков (MalSkills, SkillSieve, SkillSecurer на arXiv) — значит, проблема массовая.

## Поэтапная работа с ИИ (spec-driven development)

- Индустрия пришла к одной схеме: Amazon Kiro — требования → дизайн → задачи; GitHub Spec Kit (143 061 звезда, MIT) — спецификация → план → задачи → реализация; obra/superpowers (305 752 звезды, MIT) — понять цель → подходы → документ по размеру задачи → одобрение → план → исполнение.
- Критика (Birgitta Böckeler, Thoughtworks, martinfowler.com, октябрь 2025): на мелкой задаче — «кувалдой по ореху», мелкий баг превратился в 4 пользовательские истории с 16 критериями; проверять приходится документы вместо результата — «лучше читать код, чем все эти markdown-файлы»; вывод — нужны разные процессы для задач разного размера. https://martinfowler.com/articles/exploring-gen-ai/sdd-3-tools.html
- Что взяли: масштаб согласований под размер задачи (0, 1 или 3), разведка между целью и планом, требования на один экран.
