# Claude Code

Проверено по официальной документации 31.10.2026. Это адаптер локального Claude Code;
облачные сессии и другие продукты Claude могут иметь иной порядок подключения.

## Подключение

- Навыки проекта: `.claude/skills/panel/SKILL.md` и `.claude/skills/scout/SKILL.md`.
- Личные навыки: `~/.claude/skills/panel/SKILL.md` и `~/.claude/skills/scout/SKILL.md`.
- Явный вызов локального навыка: `/panel` или просьба «собери панель».
- Для маршрутизации используй применимый `CLAUDE.md`: в проекте или
  `~/.claude/CLAUDE.md`. Установщик добавляет блок только с `--instructions`.
  Проверь навык в каталоге текущей сессии; при необходимости перезагрузи навыки или
  начни новую сессию согласно установленной версии. Проверяй конфликты одноимённых
  навыков. Локальная установка не означает подключение навыка в облачном продукте.

## Выполнение

Обнаружь доступный инструмент `Agent` и разрешённые типы агентов. Передай каждой роли
паспорт задачи, нужные источники и формат отчёта. Название роли само по себе не создаёт
субагента. Используй подходящий доступный тип с отдельным контекстом; постоянные
определения ролей в `.claude/agents/` или `~/.claude/agents/` необязательны.

Сначала собери независимые результаты всех выбранных ролей. При фоновом запуске
дождись завершения через средства текущей версии. Сохрани возвращённые идентификаторы.
Для адресной проверки возражений используй доступное продолжение/сообщение агенту;
например, `SendMessage`, если он предоставлен. Не рассчитывай на продолжение
одноразового типа агента: если продолжение отсутствует, передай новому исполнителю
его прежний отчёт и точный вопрос, явно отметив новый контекст. Не задавай модель
жёстко и не обходи разрешения инструментов.

При лимите параллелизма запускай отдельные роли очередью. Если `Agent` недоступен или
запрещён, честно сообщи, что `full` сейчас невозможен, и предложи `quick` либо другую
среду. Не подменяй независимые отчёты диалогом персонажей в основном контексте.

## Проверка в живой сессии

После `doctor` выполни `../reference/smoke-tests.md` в Claude Code. Проверяй фактическое
подключение нужной копии навыка, запуск и получение отдельных результатов, сохранение
прежних решений в середине диалога. Успех в Codex не заменяет эту проверку.

Источники: [навыки](https://code.claude.com/docs/en/skills),
[субагенты](https://code.claude.com/docs/en/sub-agents).
