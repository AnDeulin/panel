# Личные правила — образец

При необходимости скопируйте в `learned.md` и добавляйте устойчивые предпочтения из своих правок. Файл исключён из Git. Основные правила панели уже находятся в SKILL.md; дублировать их здесь не требуется.

Записывайте предпочтения, применимые к будущим задачам, со сферой действия. Разовое решение относится к паспорту конкретной задачи. Новая явная поправка пользователя заменяет старую запись; историю существенной замены можно оставить в паспорте.

```markdown
### Формат ответа
Правило: состав и назначение ролей, краткие существенные разногласия, общий вердикт; подробности по запросу.
Применяется: работа панели.
Источник: согласованное предпочтение пользователя.
Дата: дата согласования.
```

Панель читает только применимые записи. Личные правила не дают доступа к недоступной истории и не означают разрешение на публикацию, установку программ или смену настроек.
