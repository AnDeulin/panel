# Панель экспертов — скилл для Claude Code

Скилл (навык) для [Claude Code](https://claude.com/claude-code), который на сложный вопрос
собирает не один ответ, а **панель экспертных ролей**. Claude сам подбирает роли под ваш
вопрос, роли изучают тему в интернете (локальный рынок + мировые практики, форумы, отзывы,
открытый код), спорят между собой и выдают вердикт простым языком — с приоритетами и с
указанием, в чём панель не сошлась. Решения на базе ИИ-агентов предлагаются первыми,
классические — вторыми.

Задуман для реальных бизнес-задач непрограммиста: развитие бизнеса, маркетинг, выбор ниши,
анализ конкурентов, оценка идеи, «что делать дальше». На мелких задачах (правка, факт, одна
команда) панель сама себя отключает, чтобы не жечь токены.

## Зачем это, если Claude и так отвечает

Обычный ответ — одна точка зрения. Здесь встроены три вещи, которых у одиночного ответа нет:

1. **Разные позиции и спор.** Экономист, маркетолог, скептик и профильный эксперт расходятся
   во мнениях — и вы видите, где именно, а не причёсанный консенсус.
2. **Защита от вырождения панели.** Роли высказываются сначала независимо, ведётся факт-лист
   с источниками, особые мнения фиксируются поимённо. Это лечит известную болезнь мульти-
   агентных обсуждений: когда роли сползают к общему мнению и теряют факты (см. раздел
   «На чём основано»).
3. **AI-first по умолчанию.** Панель сначала думает, как задачу закрыть ИИ-агентом (бот-
   квалификатор, автосбор отзывов, инструмент-калькулятор как лид-магнит), и только потом
   предлагает классику. С обязательной проверкой «а не театр ли это»: сколько стоит, кто
   чинит, не проще ли человек.

## Как это выглядит

Вы просто задаёте вопрос. На сложном Claude говорит «собираю панель» и ведёт вас по этапам:

```
Э1 Рамка         → пересказ вопроса своими словами + что панели неизвестно
Э2 Цель          → что считаем успехом; деньги вам и польза клиенту по сегментам
Э3 Исследование  → поиск в интернете, факт-лист с источниками
Э4 Разбор        → независимые мнения ролей → столкновение → особые мнения
Э5 План          → ГЕЙТ: вы изучаете и утверждаете. Без утверждения реализации нет
Э6 Реализация    → работа по плану → сохранение → чему научились
```

Состав ролей пересобирается на каждом этапе. Панель может задавать вопросы (с вариантами
ответов), возражать вам с аргументами и предлагать вариант лучше вашего — но, если вы
настаиваете, подчиняется и записывает расхождение, чтобы потом было видно, кто был прав.

## Установка

Нужен установленный [Claude Code](https://docs.claude.com/en/docs/claude-code).

```bash
git clone https://github.com/AnDeulin/panel.git ~/.claude/skills/panel
```

Это всё — панель уже работает. В новом диалоге Claude Code задайте сложный вопрос, и она
соберётся сама. Или позовите вручную: `/panel`, `/panel quick`, `/panel full`.

### (по желанию) Настроить под себя

Панель работает и без настройки, но с профилем отвечает точнее: подбирает роли под ваше
место и нишу, считает деньги в ваших реалиях, не предлагает строить то, что у вас уже есть.

```bash
cd ~/.claude/skills/panel
cp reference/profile.example.md reference/profile.md
```

Откройте `reference/profile.md` и заполните под себя — хотя бы коротко: кто вы, город, ниша,
что уже есть из инструментов, что считаете успехом. Чем подробнее — тем точнее панель.

Файл `learned.md` (журнал ваших правок) создавать заранее не нужно: стартовые правила уже
встроены в скилл, а личные правила панель начнёт записывать сама, когда они появятся. Оба
файла в `.gitignore` — остаются только у вас и в git не уходят.

## Команды

| Команда | Что делает |
|---|---|
| (ничего) | на сложном вопросе панель собирается автоматически |
| `собери панель` / `панель` | позвать вручную обычным языком |
| `/panel` | обычный режим: 4–6 ролей, точечный поиск |
| `/panel quick` | быстрый: 3 роли, минимум поиска — проверить идею |
| `/panel full` | полный: 6–8 ролей, широкий поиск — под дорогое решение |
| `/panel tune` | ревизия самого скилла: обновить методики, предложить правки |

## Структура

```
SKILL.md                    ядро: когда собирать, режимы, 6 этапов, формат вердикта
reference/roles.md          библиотека ролей, готовые составы, антипаттерны
reference/research.md       протокол поиска: 3 горизонта времени, 3 слоя географии, факт-лист
reference/ai-first.md       каталог агентных решений + проверка на «ИИ-театр»
reference/profile.example.md  образец профиля — копируется в profile.md (личный, не в git)
learned.example.md          образец журнала правил — копируется в learned.md (личный, не в git)
```

`SKILL.md` — единственный файл, который Claude видит всегда (точнее, только его имя и описание,
~100 токенов). Остальное подгружается по мере надобности. Это [прогрессивная загрузка](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices):
скилл не занимает контекст, пока не понадобился.

## Как настроить под себя

- **Профиль** (`reference/profile.md`) — главное. Кто вы, где, чем занимаетесь, что уже
  есть под рукой, что считаете успехом.
- **Роли** (`reference/roles.md`) — добавьте составы под свои типичные задачи.
- **Ресурсы** (`reference/ai-first.md`, раздел «Инвентаризация») — впишите свои инструменты,
  чтобы панель не предлагала строить то, что у вас уже есть.
- **Правила** (`learned.md`) — растёт сам из ваших правок; можно дописывать руками.
- **Автозапуск** — чтобы панель срабатывала без команды, добавьте в свой `~/.claude/CLAUDE.md`
  строку: на сложные запросы вызывать скилл `panel` первым.

## На чём основано

Конструкция опирается на исследования мульти-агентных систем и официальные рекомендации по
скиллам, а не на догадки:

- **Прогрессивная загрузка и структура скилла** — [Skill authoring best practices, Claude Docs](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices).
- **Почему наивная «панель» деградирует** (факты вымываются, мнения сползают к общему) —
  «The Deliberative Illusion» ([arXiv](https://arxiv.org/pdf/2606.03032)). Отсюда независимые
  мнения, факт-лист и поимённые особые мнения.
- **Дебаты дороги — применять с умом** — «Should we be going MAD?» ([ICML](https://openreview.net/pdf?id=CrUmgUaAQp)).
  Отсюда режим quick и право панели отключиться.
